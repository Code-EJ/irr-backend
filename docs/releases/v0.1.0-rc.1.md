- Final `/api/v1` modular-monolith contract and organization-scoped identity/business workflows.

- Deterministic isolated benchmark scenarios and independent report oracles.

- Portable Railway/Hostinger/other VPS manuals, backup/recovery procedures and actual synthetic public-deployment evidence.
- Container CI startup-race correction: authenticated PostgreSQL TCP readiness with a controlled slow-init regression, retaining authentication and persistence assertions.

## Install and publish

Start with [the operator manual](../deploy/operator-guide.md). Preserve PostgreSQL, Redis, RSA keys and attachments. Empty databases apply V1–V4; existing databases validate/upgrade normally. Do not reset, clean/repair or rewrite migration history for this release.

After owner approval, merge the coordinated PRs, verify main's workflows and retain the merged source SHAs. Before publishing the draft, confirm its target commit/tag and update the matched frontend/backend references in the release notes. Publish as a prerelease; keep stable production releases separate. No secrets or database snapshots belong in release assets.
